# Linux Fundamentals 

This repository contains notes from my Linux fundamentals practice for my internship task on Linux, security tools, and reconnaissance.

## Topics Covered

- Checking the current directory with `pwd`
- Listing files and directories with `ls` and `ls -l`
- Creating and entering directories with `mkdir` and `cd`
- Creating and viewing a file with `touch` and `cat`
- Understanding file permissions with `chmod`
- Viewing user and group information with `whoami` and `id`
- Viewing running processes with `ps`

## Repository Structure

- `notes/linux-fundamentals.md` — Detailed notes about the commands and concepts I practiced.
- `screenshots/` — Screenshots of my Linux command practice, if included.

## Learning Summary

I practiced basic Linux commands for navigating directories, creating files, checking permissions, and viewing user, group, and process information. I also learned why permissions matter for controlling access to files.
